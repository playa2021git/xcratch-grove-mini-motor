Xcratch Grove Mini Motor Extension

TFW-TR1（タコラッチ）に接続したGrove Mini I2C Motor Driver（DRV8830）を、Xcratchの専用ブロックで制御する拡張です。

拡張JavaScript GitHub

読み込みURL

https://playa2021git.github.io/xcratch-grove-mini-motor/grove-mini-motor.js

Xcratchでは先にAkaDako拡張を追加し、TFW-TR1を接続してください。

主な機能

  • 正転・逆転
  • 速度制御（0～63）
  • 惰性停止・ブレーキ停止
  • fault解除
